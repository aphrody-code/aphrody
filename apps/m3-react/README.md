# @aphrody/m3-react

React wrappers for **Material Web** (`md-*`) components, generated via
[`@lit/react`](https://github.com/lit/lit/tree/main/packages/react)'s
`createComponent`. The JS/TS bridge of the aphrody **Material Design 3 fusion**
(lit + material-web + shadcn + Tailwind) — see
[`docs/design/M3-FRAMEWORK.md`](../../docs/design/M3-FRAMEWORK.md).

## Pourquoi

Material Web ships framework-agnostic web components (`<md-filled-button>`, …).
React doesn't pass non-string props or listen to custom DOM events on custom
elements ergonomically; `@lit/react` `createComponent` fixes that by mapping
React props → element properties and React handlers → DOM events. This package
exposes a typed React component per `md-*` element so shadcn/React apps can use
Material 3 components directly.

## Usage

```tsx
import {FilledButton, Checkbox, OutlinedTextField} from '@aphrody/m3-react';
import '@aphrody/m3-react/theme.css'; // M3 tokens (--md-sys-color-*)

export function Demo() {
  return (
    <>
      <FilledButton>Envoyer</FilledButton>
      <Checkbox onChange={e => console.log(e)} />
      <OutlinedTextField label="Email" />
    </>
  );
}
```

## Thématisation

`theme.css` carries the M3 system colors + the shadcn/Tailwind alias sheets,
generated by `aphrody design tokens --fusion`. Regenerate with:

```sh
aphrody design tokens --fusion -o apps/m3-react/src/theme.css
```

Light/dark flips automatically through `--md-sys-color-*`. Components inherit the
tokens across the Shadow DOM. Pairs with the shadcn `theme-aphrody` registry item.
