## Notes & Recommendations

1. **Repo is already bun-first.** The only mechanical drift was two files that used
   bare `from "fs"` / `from "path"` (no `node:` prefix). Both auto-migrated.
2. **`__dirname` cleanup** is intentionally deferred. Bun supports it via the same
   compatibility layer as node; `n2b-shims/src/path.ts` already exposes
   `dirOf(import.meta)` as the canonical replacement. Migrating
   `packages/ui/scripts/build-all.ts` would require touching 5 path computations
   that produce on-disk artifacts (`StyleGuide.cs`, `theme.hpp`, `theme.py`);
   verification of output paths must accompany the change.
3. **`packages/gemini-cli/`** is a nested workspace inherited from upstream
   (`google-cli` vendor). Out of scope for this audit -- treat as vendored.
4. **No node-only patterns** (`require('node:...')`, `process.versions.node`,
   `#!/usr/bin/env node` shebangs in source) were found. The repo passes the
   strictest `feedback_bun_only` check.
