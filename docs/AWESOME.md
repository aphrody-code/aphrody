# 🌟 Awesome Google OS Resources

This document tracks official Awesome lists, references, and specifications required to build the modern 2026 Unix-like Google OS. It serves as our ultimate technical compass.

## 🦀 Rust (Pillar I: Core & Native MD3)
- **[Awesome Rust](https://github.com/rust-unofficial/awesome-rust)**: A curated list of Rust code and resources.
- **[Awesome Rust in Google](https://google.github.io/comprehensive-rust/)**: Google's internal Comprehensive Rust course.
- **[Rust OSDev](https://rust-osdev.com/)**: Resources for writing kernels in Rust.
- **[Rust for Linux](https://github.com/Rust-for-Linux/linux)**: Using Rust to write Linux kernel modules.
- **[Awesome eBPF](https://github.com/zoidbergwill/awesome-ebpf)**: Essential for modern Linux observability.

## 🛡️ C++ (Pillar II: Windows Terminal Canary)
- **[Windows Terminal](https://github.com/microsoft/terminal)**: The C++ source for the `Microsoft.WindowsTerminalCanary_8wekyb3d8bbwe!App` target.
- **[DirectX 12 & Direct2D](https://github.com/microsoft/DirectX-Graphics-Samples)**: Required for AtlasEngine text rendering optimization.
- **[Awesome Modern C++](https://github.com/rigtorp/awesome-modern-cpp)**: For understanding and extending the C++20 terminal fork.

## ⚡ Bun & JSX (Pillar III: UI & MD3 Templating)
- **[Awesome Bun](https://github.com/apvarun/awesome-bun)**: A curated list of awesome Bun resources, packages, and tools.
- **[Material Web](https://github.com/material-components/material-web)**: The official Web Components (`@material/web`) mapped by our native JSX engine.

## 🛠️ C & Kernel Space
- **[Awesome C](https://github.com/oz123/awesome-c)**: A curated list of C frameworks, libraries, and software.
- **[Awesome Linux Kernel](https://github.com/0xAX/linux-insides)**: Deep dives into the Linux kernel architecture.
- **[POSIX.1-2024 Specification](https://pubs.opengroup.org/onlinepubs/9799919799/)**: The definitive UNIX standard.

## 🐧 Linux
- **[Awesome Linux](https://github.com/aleksandar-todorovic/awesome-linux)**: A comprehensive list of awesome Linux software, environments, and resources.
- **[Linux Insides](https://github.com/0xAX/linux-insides)**: Deep dives into the Linux kernel architecture and its internals.
- **[Awesome eBPF](https://github.com/zoidbergwill/awesome-ebpf)**: Essential tools and reading for modern Linux observability.
- **[Awesome Sysadmin](https://github.com/kahun/awesome-sysadmin)**: A curated list of amazingly awesome open source sysadmin resources.

## ⚙️ Windows & Virtualization
- **[Awesome Windows OS](https://github.com/Awesome-Windows/Awesome)**: A curated list of awesome Windows software and architecture references.
- **[Windows Internals](https://learn.microsoft.com/en-us/sysinternals/resources/windows-internals)**: Mandatory reading for bypassing NTDLL (used in `bun_ffi`).

## 📦 Asset Optimization (Standard 2026)
- **[Oxipng](https://github.com/shssoichiro/oxipng)**: High-performance Rust multithreaded PNG compressor.
- **[SVGO](https://github.com/svg/svgo)**: The absolute standard for SVG XML minification.
- **[LightningCSS](https://lightningcss.dev/)**: Rust-based extreme CSS minifier.
- **[Sharp](https://sharp.pixelplumbing.com/)**: C++ libvips wrapper for ultra-fast AVIF/JXL transcoding.
