# Google Design

> design.google is Google's design publication and library: articles, interviews,
> guides, and case studies on how Google approaches design across Material, typography,
> color, motion, AI/Gemini, hardware, and accessibility. This is an llms.txt-format index
> enumerated from the site sitemap (https://design.google/sitemap.xml, fetched 2026-05-29)
> and grouped by theme. One line per page: title + URL + a distilled one-line description
> (our own words / the page's own meta description, summarized; no verbatim article bodies).
>
> Source: https://design.google (Google), fetched 2026-05-29. The library holds ~300
> articles; this index links the category/index pages plus a thematically complete
> selection of the design-language-relevant articles. The full URL list lives in the
> sitemap. For the M3 specification itself see docs/design/m3-material-io-llms.txt.
>
> Distilled in-repo companions: docs/design/references/gemini-visual-language.md,
> docs/design/references/google-sans-family.md, docs/design/google/ANALYSE.md.
