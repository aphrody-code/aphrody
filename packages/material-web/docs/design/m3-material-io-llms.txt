# Material Design 3

> Material Design 3 (Material You) is Google's open-source design system. This is an
> llms.txt-format index of the canonical specification site https://m3.material.io,
> enumerated from its sitemap (https://m3.material.io/sitemap.xml, fetched 2026-05-29)
> and grouped by the site's own navigation (Get started, Foundations, Styles,
> Components, Develop, Blog). One line per page: title + URL + a distilled one-line
> description. Descriptions are summaries in our own words, not verbatim article text.
>
> Source: https://m3.material.io (Google, Apache-2.0 / CC-BY content), fetched 2026-05-29.
> Web caveat: m3.material.io is an Angular single-page app rendered client-side, so its
> page bodies are not available as plain text via a simple fetch; canonical numeric values
> (type scale, shape, motion, elevation, state layers) live in this repo's corpus
> (docs/01-md3-spec-foundations.md) and the material-foundation GitHub token sources.
> Web reality: @material/web implements the tokenized M3 "classic" foundations only;
> M3 Expressive (springs, shape morphing, split buttons, button groups, FAB menus,
> loading indicators, docked toolbars, emphasized type) is Android/Compose-only as of 2026.
