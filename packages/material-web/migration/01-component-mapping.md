# Mapping exhaustif MUI → material-web (composant par composant, props/slots/events vérifiés)

Ce document fournit le **mapping vérifié, composant par composant**, de `@mui/material@9.0.1` (`material-ui/packages/mui-material/src/`, ~100 composants réels) vers le fork `@material/web@2.4.1` (`material-web/`, 93 éléments `<md-*>` réels listés dans `migration/scripts/md-elements.txt`). Pour chaque composant : élément `md-*` cible (par variante), wrapper React (nommage §2 du contrat), mapping des **props** (noms réactifs Lit réels — vérifiés dans les sources, jamais devinés), mapping des **slots**, mapping des **events**, et pièges/pertes de fidélité. Les composants sans équivalent sont marqués **GAP** et renvoyés vers `05-gap-analysis.md`. Aucun tag hors `md-elements.txt` n'est utilisé. Tous les noms cités sont sourcés en `repo/chemin:ligne`.

> **Rappels transverses (contrat §4) appliqués partout, non répétés ligne à ligne :**
>
> - MUI `value` + `onChange(e, value)` → md émet des **events DOM natifs** `input`/`change` (re-dispatchés depuis l'`<input>` interne via `redispatchEvent`, ex. `material-web/textfield/internal/text-field.ts:728`, `material-web/checkbox/internal/checkbox.ts:178`, `material-web/select/internal/select.ts:817`). Le wrapper expose `onInput`/`onChange` via `events` de `createComponent`. **La signature React change** : lire `e.target.value` (et non `(e, value)`).
> - `sx` → pas d'équivalent ; convertir en `style`/utilitaires Tailwind sur le host (ne traversent **pas** le shadow DOM). Theming interne = tokens `--md-sys-*`.
> - `disabled` existe sur la plupart des contrôles via le mixin form-associated (`material-web/labs/behaviors/form-associated.ts:35`) — mapping 1:1.
> - Icônes : `startIcon`/`endIcon` MUI → `<md-icon slot="icon">`, ou `slot="start"`/`slot="end"` selon l'élément.

## 9. Index des GAP

Composants MUI **sans équivalent md** (détails + shims dans `05-gap-analysis.md`) :

- **Feedback / surface :** `Alert`, `AlertTitle`, `Skeleton`, `Backdrop`.
- **Données / media :** `Avatar`, `AvatarGroup`, `Rating`.
- **Navigation :** `Breadcrumbs`, `Link` (→ `<a>` tokenisé), `MobileStepper`, `Pagination` à pastilles (vs `md-paginator` type TablePagination).
- **Primitives / overlay :** `Modal`, `Popover`, `Popper`, `ClickAwayListener`, `Portal`, `NoSsr`, `Unstable_TrapFocus`.
- **Transitions :** `Collapse`, `Fade`, `Grow`, `Slide`, `Zoom` (→ motion tokens `--md-sys-motion-*`).
- **Global / thème :** `CssBaseline`, `ScopedCssBaseline`, `GlobalStyles`, `InitColorSchemeScript`, `DefaultPropsProvider` (→ `02-theme-token-migration.md`).
- **Cas avancés partiels :** `Select multiple`, `Autocomplete` (`multiple`/`freeSolo`/`groupBy`/`renderOption`), `Table` très custom, `TextField variant="standard"`, `Slider` markers riches.

Tous les **layout** (`Box`/`Container`/`Stack`/`Grid`/`Paper`) ne sont pas des GAP fonctionnels : ils se résolvent en `<div>` + Tailwind / `md-elevation` (cf. `06-tailwind-material-web.md`).
