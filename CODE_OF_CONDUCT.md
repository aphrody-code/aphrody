# Code of Conduct

This project adopts the **Contributor Covenant v2.1** as its code of conduct.
The full text is canonical at:

- <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>
- (Translations and machine-readable formats also linked from that page.)

## Scope

Applies in all project spaces — GitHub issues, PRs, Discussions, commit
messages, code review comments — and any time a contributor represents the
project publicly (talks, blog posts, social media mentioning aphrody).

## Reporting

Send reports to **conduct@aphrody-code.dev**.

If the report concerns a maintainer, escalate to the noreply address listed
in the [LICENSE](LICENSE) header.

All reports are reviewed within 7 days. Reporter identity is kept
confidential except where disclosure is required to address the report.

## Enforcement

Enforcement actions follow the Contributor Covenant's standard ladder:
private correction → public warning → temporary ban → permanent ban. The
maintainer team decides; appeals go to the same address.
