# Contributors

## 1. Recognition

Every contributor to `aphrody-code/aphrody` is listed here. Format: GitHub
handle plus a one-line role or first significant contribution.

## 2. Maintainers

- `@aphrody-code` — repo owner, primary maintainer.

## 3. Contributors

_When the first external contributor lands, add their handle here,
alphabetically. Initial state: empty (autonomous-loop bootstrap, no external
contributors yet)._

## 4. AI agents

This project is meta — it is about AI agent coordination. Agents that have
meaningfully contributed code or docs are recognised below for transparency:

- **Claude Code (Claude Opus 4.7)** — autonomous YOLO grind operator,
  bootstrapped 2026-05-17 (run cohort of 19+ ticks, ~80+ deliverables;
  cf. `docs/posts/2026-05-yolo-grind-loop.md`).
- _Future agents (Cursor, Continue, OpenAI Codex, Gemini, etc.) when they
  contribute, list here._

Per `AGENTS.md` (_when published_), AI agent contributions land WITHOUT
`Co-Authored-By` trailers in commit messages (anti-fingerprint policy); they
ARE recognised here as a transparency and acknowledgement mechanism.

## 5. How to add yourself

- Open a PR that adds your line under §3 Contributors after your first merged
  PR.
- Format: `- @handle — <role or first contribution one-liner>`.
- See [`CONTRIBUTING.md`](CONTRIBUTING.md) for the full PR process.

## 6. Security researchers

Security researchers who responsibly disclose are listed in
[`SECURITY-HALL-OF-FAME.md`](SECURITY-HALL-OF-FAME.md) instead — that is the
dedicated thank-you file for security work.
